AI Tuberculosis Detection & Pseudo-3D Lung Visualization

Development Timeline

1. Research

Acquired TBX11K dataset, studied current clinical challenges with 2D X-Rays.

2. Prototyping

Tested basic CNNs. Poor lesion localization. Integrated Grad-CAM.

3. Architecture Shift

Moved to YOLOv8 + U-Net. Added MiDaS for pseudo-depth generation.

4. Deployment

Rendered interactive 3D visualizations in the browser using Three.js.

System Architecture

Input X-Ray
U-Net Segmentation
YOLOv8 + MiDaS
Three.js Render

Lessons Learned & Failures

Initial Failure: Started the project using basic CNN architectures (ResNet) to draw bounding boxes around lesions. The bounding boxes were too inaccurate and provided no anatomical context to clinicians.

The Pivot: I realized pixel-perfect semantic segmentation was required. I switched to a U-Net architecture to mask the lungs perfectly, and layered YOLOv8 for precise lesion localization, drastically improving the utility of the tool.
